# `_LLM报告数据.json` 结构说明

> 仅在需要直接解析 / 撰写报告时才读本文件。日常查询走 `risk_result_query`。

## 顶层结构

```
{
  "报告目标":       str              # 业务背景句
  "分析概览":       object           # 见下
  "核心发现":       list[str]        # 5-8 条自动提炼的要点句
  "特征有效性汇总": list[object]     # 核心/重要/辅助特征，每个特征一个 object
  "无效特征列表":   list[str]        # 无效特征名称列表
  "分群画像_重点":  list[object]     # 重点分群，完整字段
  "分群画像_简略":  list[object]     # 其余分群，精简字段
  "维度去重说明":   object           # 可选，高度重叠维度的处理说明
}
```

## `分析概览` 字段

```
{
  "数据概况": { "总样本数", "坏客户数", "坏客户率" }
  "分群维度": { "类别型维度": list, "类别型维度数量", "资质标签维度": list, "资质标签维度数量" }
  "特征集":   { "特征数量", "特征列表摘要": list[str] }   # 仅前10个
  "分析范围": { "参与分析的分群总数", "IV可信率>=50%的分群数", "IV可信率<50%的分群数" }
  "可信度告警": list[str]
}
```

## `特征有效性汇总[*]` 字段（每个特征一行）

| 字段 | 说明 |
|------|------|
| `特征名称` | 特征列名 |
| `特征类型` | 原始 / 衍生 / 空 |
| `全局IV` | float |
| `IV预测力` | 强 / 中 / 弱 / 无 |
| `IV可信度` | 可信 / 参考 / 不可信-* |
| `可信分群平均相关系数` | float / null |
| `可信分群相关系数极差` | float / null |
| `可信分群分析数` | int |
| `跨分群方向一致` | bool |
| `跨分群一致性` | 高 / 中 / 低 |
| `可信分群平均LR系数` | float / null |
| `综合评级` | 核心特征 / 重要特征 / 辅助特征（无效特征在 `无效特征列表`） |

> 按综合评级排序：核心 > 重要 > 辅助，同级按 `全局IV` 降序。

## `分群画像_重点[*]` 字段

| 字段 | 说明 |
|------|------|
| `分群维度` | |
| `分群名称` | |
| `样本数`, `坏客户数`, `坏客户率` | |
| `模型AUC` | float / null |
| `AUC类型` | 5折交叉验证 / 训练集(样本不足) / 训练集(CV失败) |
| `IV可信率%` | float |
| `风险特征概要` | 自动生成的一句话描述 |
| `Top3预测特征_IV` | `特征名(IV值), ...` 格式字符串 |
| `Top3风险特征_相关性` | `特征名(±相关系数), ...` 格式字符串 |
| `特征集优胜` | 原始 / 衍生 / 持平（可选，有特征集对比时才有） |

## `分群画像_简略[*]` 字段

仅含：`分群维度` / `分群名称` / `样本数` / `坏客户数` / `坏客户率` / `模型AUC` / `AUC类型` / `风险特征概要`

## 重点分群判定规则

满足以下任一条件即进入「重点分群」：
- 坏客户率 > 全局坏客户率 × 1.5
- 模型 AUC ≥ 0.65（且来自 5 折交叉验证）
- IV 可信率 ≥ 50%

其余进入「简略分群」。

## 常见访问模式

```python
import json
with open('xxx_LLM报告数据.json', encoding='utf-8') as f:
    data = json.load(f)

# 高层结论
print(data['核心发现'])

# 有效特征列表（综合评级非无效）
core = [f for f in data['特征有效性汇总'] if f['综合评级'] == '核心特征']

# 重点分群画像
for seg in data['分群画像_重点']:
    print(seg['分群名称'], seg.get('Top3预测特征_IV', ''))

# 也可通过 load_results 读取（已加载到 r.llm_report）
from risk_result_query.scripts import load_results
r = load_results('项目名')
data = r.llm_report   # 等价于上面的 json.load 结果
```
