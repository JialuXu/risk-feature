# 图表类型参考（按需阅读）

> 设计原则：本 skill 只产**面向最终业务报告**的图——全局概览 + 每个分群维度一张的
> 热力图/对比图，不产每分群散图等会随分群数量爆炸的细图。

## 标准分析图

### 1. 全量 IV 横向条形图 (`iv`)

- **用途**：一图回答"哪些特征整体预测能力最强"
- **着色规则**：按 `IV_LEVEL_BINS` 分箱（强/中/弱/无），与 IV 诊断口径一致
- **常见误读**：IV > 2.0 的特征已在分析阶段标"疑似数据穿越"，本图保留显示但用斜线条纹标注，**不应直接进入结论推荐**
- **限制**：只展示全量 IV，分群 IV 看 `iv_heatmap`

### 2. 分群 × 特征 IV 热力图 (`iv_heatmap`)

- **纵轴（行）**：同一维度下的各分群（如 `企业规模` → 大型/中型/小型/微型企业），**横轴（列）**：特征（取全量 IV top-N）
- **每个`分群维度`一张图**（与 corr_heatmap / lr_heatmap 同口径，不把不同维度的分群混排在一张表里）
- **颜色**：IV 值（蓝→红，0 → 疑似数据穿越线）
- **叠加**：可信度为「不可信」的单元用 `X` 文字覆盖（来自分群 IV 长表的 `IV可信度` 列）
- **业务读法**：固定一行 = 该分群的"特征预测力画像"；扫一列 = 同一指标在该维度不同分群是否都好用
- **常见误读**：单元颜色深 + 带 X = "样本不足以信任 IV"，不要因为颜色深就引用

### 3. 分群 × 特征 相关系数热力图 (`corr_heatmap`)

- **纵轴（行）**：分群名称，**横轴（列）**：特征 top-N（按"该维度内 |corr| 最大值"全局排序）
- **颜色**：发散色阶以 0 为中心（红=负相关，蓝=正相关），范围对称
- **每个`分群维度`一张图**（默认；用 `dim=` 可限制到单一维度）
- **业务读法**：同一列里出现红蓝切换 = 该特征跨分群符号冲突，**不应直接进入通用规则**
- **何时不该用**：分群只有 1 个时退化成单行，没意义

### 4. 分群 × 特征 LR 系数热力图 (`lr_heatmap`)

- **纵轴（行）**：分群名称，**横轴（列）**：特征 top-N（按"该维度内 |系数| 最大值"全局排序）
- **颜色**：发散色阶以 0 为中心（红=负向，蓝=正向），范围对称
- **每个`分群维度`一张图**（默认；用 `dim=` 可限制到单一维度）
- **业务读法**：同一列里出现红蓝切换 = 该特征在不同分群里方向不一致，**对应分群应单独建模或单独定阈值**
- **与 corr_heatmap 的区别**：corr_heatmap 看"线性相关"，lr_heatmap 看"控制其他特征后的边际贡献"；两者结论不一致时以 LR 为准（已控制混杂）

### 5. 跨分群 AUC 条形图 (`auc`)

- 一张图汇总所有分群的 AUC
- **着色**：按 AUC 类型（`交叉验证` / `训练集-样本不足` / `训练集-CV失败`）分色
- **常见误读**：训练集 AUC 通常虚高，柱子高 ≠ 模型好，要看色

### 6. 分群画像图 (`segment`)

- 各分群坏客户率柱图，柱顶标注样本数（n=...）
- 红色基准线 = 整体坏客户率

## 规则 / 指标组合图

### 7. 规则 lift × coverage 散点 (`rules`)

- 横扫所有规则的"准 vs 覆盖"权衡：x = 覆盖率（log scale），y = lift（log scale）
- **气泡大小** = 命中坏客户数；**颜色** = 稳定性等级
- **理想区**：右上（高 lift + 高覆盖），通常落在中部
- **常见误读**：左上（lift 高但覆盖极低）= 边缘规则，不是好规则

### 8. 指标组合 max lift 条形图 (`combos`)

- 把 `涉及特征` 排序去重做 key，聚合：`max(lift) / sum(coverage_pct) / count(rule_id)`
- y 轴 = 特征组合（"特征A + 特征B"）；x 轴 = 该组合下最高 lift
- 柱色 = 合计覆盖率；右侧标注命中规则数
- **用法**：发现"哪几组指标组合起来最具区分力"，是规则 + LR 之外的另一种视角

### 9. 候选阈值图 (`thresholds`)

- 仅在跑过 `explore_thresholds` 后有数据；分箱坏率图 + 风险倍数对比图
- **业务读法**：特征超过候选阈值后坏率抬升几倍，可直接转述为"X ≥ 阈值 → 坏率 N 倍"

## 共同约定

- 输出目录：`output/<project>/charts/`（沿用 default.yaml 的 `output:` 根目录）
- 文件名：`<kind>[_<dim>][_topN].png`，例：`lr_heatmap_企业规模_top15.png`、`corr_heatmap_企业规模_top15.png`
- DPI：默认 300（高清）；调用方可传 `dpi=` 覆盖
- 中文字体：`font_utils.py` 自动按 OS 探测；缺字体只 warn
- 跳过规则：缺少必要 CSV 时打印 `[跳过 <kind>] 缺少 ...`，**不抛异常**，让其余图能继续
