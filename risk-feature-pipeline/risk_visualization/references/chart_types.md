# 图表类型参考（按需阅读）

## 标准分析图

### 1. 全量 IV 横向条形图 (`iv`)

- **用途**：一图回答"哪些特征整体预测能力最强"
- **着色规则**：按 `IV_PREDICTION_LEVELS` 分箱（强/中/弱/无），与 IV 诊断口径一致
- **常见误读**：IV > 2.0 的特征已在分析阶段标"过拟合嫌疑"，本图保留显示但用斜线条纹标注，**不应直接进入结论推荐**
- **限制**：只展示全量 IV，分群 IV 看 `iv_heatmap`

### 2. 分群 IV 热力图 (`iv_heatmap`)

- **行**：分群（分群维度+分群名称），**列**：特征（取全量 IV top-N）
- **颜色**：IV 值（蓝→红）
- **叠加**：可信度不足的单元用 `✗` 文字覆盖（来自 `_IV可信度透视表.csv`）
- **常见误读**：单元颜色深 + 带 ✗ = "样本不足以信任 IV"，不要因为颜色深就引用

### 3. 分群相关系数条形图 (`corr`)

- 每个分群一张图；横向条形，正系数蓝、负系数红
- 适合写"在 X 分群中，Y 特征与坏客户呈现正相关"这类描述

### 4. LR 系数条形图 (`lr`)

- 每个分群一张图；按 `|系数|` 排序取 top-N，正负双色
- **注意**：图中是标准化后的系数，量纲已归一；但跨分群比较仍需谨慎（两分群的样本量、特征分布可能差异大）

### 5. 跨分群 AUC 条形图 (`auc`)

- 一张图汇总所有分群的 AUC
- **着色**：按 AUC 类型（`交叉验证` / `训练集-样本不足` / `训练集-CV失败`）分色
- **常见误读**：训练集 AUC 通常虚高，柱子高 ≠ 模型好，要看色

### 6. 分群画像图 (`segment`)

- 各分群坏客户率柱图，柱顶标注样本数（n=...）
- 红色基准线 = 整体坏客户率

## 决策树 / 指标组合图

### 7. 决策树图 (`tree`)

- **路线 B（首选，pkl 存在时）**：用 `sklearn.tree.plot_tree` 渲染，每个内部节点显示 `特征 <= 阈值 / gini / samples / value`，叶子着色 = 坏客户率
- **路线 A（降级）**：从 `_风险规则表.csv` 反推路径，按 `规则条件` 文本拆 `(特征, op, 阈值)`，按公共前缀拼回二叉分裂
- 路径还原图叶子标注：`bad_rate / coverage / lift / stability`
- 多个 scope（全样本 / 各分群）会出多张图
- **何时不该用**：树太深（>4）时画出来不可读，建议先在 `rule_mining.max_depth` 限制深度

### 8. 规则 lift × coverage 散点 (`rules`)

- 横扫所有规则的"准 vs 覆盖"权衡：x = 覆盖率（log scale），y = lift（log scale）
- **气泡大小** = 命中坏客户数；**颜色** = 稳定性等级
- **理想区**：右上（高 lift + 高覆盖），通常落在中部
- **常见误读**：左上（lift 高但覆盖极低）= 边缘规则，不是好规则

### 9. 指标组合 max lift 条形图 (`combos`)

- 把 `涉及特征` 排序去重做 key，聚合：`max(lift) / sum(coverage_pct) / count(rule_id)`
- y 轴 = 特征组合（"特征A + 特征B"）；x 轴 = 该组合下最高 lift
- 柱色 = 合计覆盖率；右侧标注命中规则数
- **用法**：发现"哪几组指标组合起来最具区分力"，是规则 + LR 之外的另一种视角

### 10. 特征共现网络 (`combo_network`)

- 节点 = 在规则中出现过的特征
- 节点大小 = 该特征出现的规则数
- 边 = 任两特征在同一条规则中共现；边粗 = 共现规则数
- 布局 = 圆形（matplotlib 自绘，无 networkx 依赖）
- **用法**：识别"哪几个指标常常被树挑出来组合"，反向辅助特征工程

## 共同约定

- 输出目录：`output/<project>/charts/`（沿用 default.yaml 的 `output:` 根目录）
- 文件名：`<kind>[_<dim>__<group>][_topN].png`，例：`lr_企业规模__小型企业_top15.png`
- DPI：默认 300（高清）；调用方可传 `dpi=` 覆盖
- 中文字体：`font_utils.py` 自动按 OS 探测；缺字体只 warn
- 跳过规则：缺少必要 CSV 时打印 `[跳过 <kind>] 缺少 ...`，**不抛异常**，让其余图能继续
