### 一、报告整体结构

1. **分析背景与数据概况**：说明研究目的（通过贷后数据分析反哺贷前，强化风险识别、提升贷前准入时风险筛查能力、以及给贷前的人员做风险提示），简述数据范围、方法论概要（机器学习分群+IV值+逻辑回归验证）。

2. **企业客户风险特征分析**：
   每个维度下包含三个层次：
   - **数据分析**：交代样本量、坏客户数、坏客户率、分群维度数、IV可信率等关键统计指标（用"指标-数值"简表呈现），说明使用了哪些原始特征和衍生特征，以及交叉分群维度。
   - **主要风险特征**：
     - 先给出**特征总览表**，将特征分为"核心特征 / 条件特征 / 无效特征"三档，列出全局IV值、跨分群一致性、业务含义。
     - 再按**各分群维度**逐一展开分析，每个分群：
       a) 先概述该维度下整体的数据表现，以及哪些特征IV值较强；
       b) 在每个分群（维度下的子分群如“国有控股”）中，选取**其中相对来说更具区分力的特征**做深入解读，包含：相关性方向与系数的数据表现、风险客户vs非风险客户的均值对比、业务逻辑解释；（按照分群去描述特征，不要以特征为章节描述每个分群下表现）
       c) 给出**具体的业务建议**，语气为"建议客户经理关注…""应重点关注…""核实…"；
     - 每个分群维度末尾附一张汇总表：分群名、样本数、坏客户率/风险客户占比、模型AUC、首要风险特征(含回归系数方向)。
   - **后续业务建议**：按"维度：XX+风险特征"逐条列出，简要说明。
3. **腰部企业分析**：
   针对授信规模分层为腰部的企业进行专题分析。
   先描述腰部企业定义和基础画像
   然后再进行核心风险特征排名
   再进行风险特征的深度解读
   最后再完成对腰部企业的画像总结
4. **跨纬度交叉发现**：
   通过对比各分群的分析结果，提炼跨纬度的关键交叉发现。
   比如：某些指标的反转规律、普适性等等。
5. **数据质量与后续的工作建议**：
   请你直接根据数据解读结果200字以内表述。

### 二、写作风格要求
1. **语体**：正式公文+专业分析混合风格，使用银行风控术语（如"尽调""准入""授信分散度""同业认可度""资金饥渴""信用资质恶化"等）。
2. **数据呈现**：关键数字必须精确引用（样本数、占比、IV值、回归系数、均值对比），用括号标注方向如"(+0.198)"。
3. **因果逻辑**：每个风险特征必须给出"数据表现→业务含义→风险逻辑→操作建议"的完整推理链。
4. **概括标签**：每个分群的风险逻辑用简短标签概括，如"授信渠道分散"。
5. **图表引用**：在正文中以"详见图X""详见表X"引用，图表标题格式为"图X. 维度名&数据类型-描述"。
6. **可信度门槛（硬规则）**：IV可信度为"不可信-*"档（如"不可信-样本不足""不可信-过拟合嫌疑"）的特征，不得纳入报告的结论与建议；如确需提及，必须显式标注其不可信原因，并说明仅作背景参考。
