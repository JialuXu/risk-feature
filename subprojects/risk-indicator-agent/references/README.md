# references/（本地参考资料，不入库）

本目录只有本说明文件入库。运行 Step 2/3 前在本地放入：

| 文件 | 用途 | 列 |
|---|---|---|
| `表清单.csv` | 字段字典（表级） | 表英文名, 表中文名 |
| `表字段清单.csv` | 字段字典（字段级） | 表英文名, 字段英文名, 字段中文名, 字段类型 |

可选的设计文档（`工作链路-指标设计方法论.md`、`衍生指标层数据结构设计文档.md`、`原始加工逻辑整合纪要.md`）也放这里。

格式参照 `tests/fixtures/references/` 下的合成示例。也可以在 `config/local.yaml` 里用
`paths.references_dir` 指向其它目录，或者用软链接指过去。
