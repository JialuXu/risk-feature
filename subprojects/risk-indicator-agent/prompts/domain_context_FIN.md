# 财务域 (FIN) · 业务上下文

## 业务定位

财务域指标基于客户提供的财务报表 (资产负债 / 利润 / 现金流). 在我行场景下:

- **覆盖率低** (~30% 客户有完整财报), 因此必须考虑稀疏场景
- 高缺失指标进 P1-稀疏池, 而不是直接丢
- 财报真实性是另一个独立问题, 不在指标层处理 (有专门的"财务质量"维度)

## 主要基础表

- `DT_SSDP_CROP_CUST_FNC_IDX_A` —— 对公客户财务指标 (资产负债表 + 利润表 + 现金流表)
- `DT_SSDP_CORP_CUST_CRDT_IND_W` —— 对公客户授信指标 (用于本行授信使用率类)
- `DT_SSDP_CORP_CUST_BASIC_INFO_W` —— 基础信息 (规模 / 行业)

## 命名约定

- `FIN_M_<业务键>_<窗口>_<统计>`
- 偿债能力类: `FIN_M_DEBT_<X>_<W>_RATIO`
- 资产质量类: `FIN_M_AR_INV_<W>_RATIO`
- 经营效率类: `FIN_M_TURNOVER_<X>_<W>_RATIO`
- 盈利质量类: `FIN_M_PROFIT_<X>_<W>_RATIO`
- 现金流类: `FIN_M_CF_<X>_<W>_RATIO`
- 本行授信类: `FIN_M_CGB_<X>_<W>_RATIO`

## 设计模式约定

- `ref_date_logic`: 多数 SNAP, 同比/增长率类用 EXPLICIT_PARAM (年报快照日)
- `null_handling`: `KEEP_NULL` + `SAFE_DIVIDE_NULL` (财务比率分母为 0 通常代表数据异常,而非业务上 0)
- `post_processing_rule`: `KEEP_NULL_ON_LEFT_JOIN` (无财报客户保留 NULL,不补 0)

## 风险方向常识

- 偿债能力指标 (流动比率/速动比率/现金比率) → 大者风险低 (负向)
- 杠杆类 (资产负债率/借款依赖度/权益乘数) → 大者风险高 (正向)
- 盈利能力 (ROA/ROE/毛利率) → 大者风险低 (负向)
- 经营效率 (各类周转率) → 大者风险低 (负向)
- 本行授信使用率 → 大者风险高 (正向)
- 同比/环比下降幅度大 → 通常正向 (恶化)

## 注意事项

- 财务指标多数信号弱 (IV < 0.05), 但稳定且可解释,首版主要做 "可注册可观察";不强求每条都进 P0
- 财务真实性核验是上游问题, 假账会让所有指标失效 — 在 notes 中可写 "依赖财务真实性,建议结合『财报来源真实性』维度共同使用"
